MP3를 편집한다는 건, 짧은 목록 중 하나인 경우가 많아요. 구간을 자르거나, 무음을 빼거나, 끝을 페이드하거나, 키우거나, 속도를 바꾸거나, 플레이어에 나오는 제목을 고치거나. 각 일에는 이미 페이지가 있어요. 이 페이지는 지도예요. 파일을 세 번 디코딩하고 세 번 인코딩하지 않으려고요.

[MP3 편집기](/ko/mp3-editor)가 일반적인 경우예요. 파일을 놓고, 고치고, 한 번 내보내요. 원본은 디스크에 남아요. 새 파일은 다운로드예요.

## 어떤 일인지

| 하고 싶은 일 | 여는 곳 |
|---|---|
| 음성 메모를 줄이거나 무음을 지우기 | [오디오 자르기](/ko/guides/how-to-trim-audio) |
| 파일 여러 개를 이어 붙이기 | [오디오 합치기](/ko/guides/merge-songs-one-track) |
| 제일 좋은 40초를 벨소리로 | [벨소리 만들기](/ko/guides/make-iphone-ringtone) |
| 빠르게 또는 느리게. 음정도 같이 움직임 | [노래 배속](/ko/change-audio-speed) |
| 제목, 아티스트, 표지 | [MP3 태그 편집기](/ko/mp3-tag-editor) |
| 영상에서 소리만 빼기 | [MP4를 MP3로](/ko/guides/convert-video-to-mp3) |

일이 자르기, 페이드, 음량처럼 작은 것 두세 개면, MP3 편집기에서 하고 한 번만 내보내요. 슬라이더마다 새 페이지를 열면, 열 때마다 MP3를 다시 인코딩해요.

## 한 번에

MP3를 [편집기](/ko/mp3-editor)에 놓으세요. 파형은 탭 안에서 디코딩된 파일이에요.

구간을 드래그하세요. **선택 남기기** 는 그 부분만 내보내요. **선택 지우기** 는 나머지를 내보내요. 드래그가 부족하면 **정확한 시간** 에 시작과 끝을 초로 적어요.

나머지는 **조절** 에 있어요.

- **페이드 인** 과 **페이드 아웃** 은 최대 5초. 내보내는 파일의 시작과 끝을 다듬어요. 파일 가운데의 이음은 크로스페이드하지 않아요.
- **음량** 은 10%에서 200%. 100%를 넘으면 리미터가 피크를 잡아요. 조금 키우는 편이 딱딱하게 클리핑하는 것보다 깨끗해요. 이미 큰 파일은 그래도 조여서 들려요.
- **속도** 는 0.5×에서 2×. 음정도 같이 움직여요. 키는 두고 길이만 바꾸는 처리가 아니에요.
- **피크 정규화** 는 가장 큰 샘플이 클리핑 직전에 올 때까지 파일 전체를 같은 양만큼 올려요. 음량 슬라이더를 덮어써요. 작은 부분을 큰 부분만큼 크게 만들지는 않아요.
- **거꾸로** 는 내보내기를 끝에서 앞으로 뒤집어요.

내보내기 전에 선택 구간을 재생해서 들으세요. 그다음 형식이에요.

**MP3 · 320 kbps** 가 편집기의 기본이고, 이 내보내기를 남길 파일이면 이거예요. 보내기만 하면 **192 kbps**. 말은 **128 kbps**. 이 편집이 마지막이 아니면 **WAV**.

## 크기를 찍지 않기

처음부터 끝까지 작은 파일에는 정직한 방법이 두 개 있어요. 같은 손잡이가 아니에요.

[오디오 정규화](/ko/normalize-audio)는 피크를 재고, 클리핑하지 않는 가장 큰 게인을 걸어요. 얼마나 올릴지 모를 때 써요.

[MP3 음량 키우기](/ko/increase-volume)는 직접 고르는 배수예요. 최대 400%이고, 피크에 리미터가 있어요. 편집기의 음량은 200%에서 멈춰요. 200%로 부족할 때가 전용 페이지예요. 큰 부분이 펌핑하기 시작하면 뒤로 빼세요.

둘 다 스트리밍용 라우드니스 맞추기는 아니에요. 그건 LUFS로 재는 긴 평균이고, 마스터링 일이에요.

## 소리와 이름은 따로

자르고, 페이드하고, 키우는 일은 MP3를 디코딩해서 새 파일을 써요. 제목, 아티스트, 앨범, 표지는 소리가 아니에요. 태그 블록에 있고, [태그 편집기](/ko/mp3-tag-editor)는 그 블록만 다시 쓰고 오디오 바이트는 건드리지 않아요. 소리를 먼저. 남길 파일에 이름을 붙이세요. 이름을 먼저 붙이고 새 MP3를 내보내면, 태그는 나가는 길에 떨어져요.

태그 편집기는 MP3만 돼요. 앨범을 한꺼번에 다루지 않고, 특이한 팟캐스트 챕터 칸도 옮기지 않아요.

## 이 편집기가 안 하는 일

트랙 두 개를 겹쳐 믹스하지 않아요. [오디오 합치기](/ko/audio-joiner)는 파일을 앞뒤로 놓고, 겹치는 부분을 크로스페이드할 수 있어요. 페이더 두 개를 동시에 주지는 않아요.

보컬을 지우거나, 노이즈 프로파일을 찍거나, 곡을 스템으로 나누지도 않아요. 그걸 약속하는 브라우저 페이지는 다른 제품을 말하는 거예요.
