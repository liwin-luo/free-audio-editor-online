MP3 を編集する、というのは短い一覧のどれか一つであることが多いです。区間を切る、無音を落とす、端をフェードする、大きくする、速さを変える、プレーヤーに出るタイトルを直す。それぞれにページがあります。このページは地図です。ファイルを三回デコードして三回エンコードしないためです。

[MP3 エディター](/ja/mp3-editor) が一般の場合です。ファイルを置き、編集し、一度書き出します。元のファイルはディスクに残ります。新しいのはダウンロードです。

## どの作業か

| したいこと | 開くページ |
|---|---|
| ボイスメモを短くする、無音を消す | [音声をトリミングする](/ja/guides/how-to-trim-audio) |
| 複数のファイルを順番につなぐ | [音声を結合する](/ja/guides/merge-songs-one-track) |
| いちばんいい 40 秒を着信音にする | [着信音を作る](/ja/guides/make-iphone-ringtone) |
| 速く、または遅くする。音程も一緒に動く | [音声の速度変更](/ja/change-audio-speed) |
| タイトル、アーティスト、ジャケット | [MP3 タグエディター](/ja/mp3-tag-editor) |
| 動画から音だけ取る | [MP4 を MP3 にする](/ja/guides/convert-video-to-mp3) |

作業がカットとフェードと少しの音量、のように小さいものが二つか三つなら、MP3 エディターでまとめて一度書き出します。スライダーごとに別ページを開くと、そのたびに MP3 をエンコードし直します。

## 一度で終える

MP3 を [エディター](/ja/mp3-editor) に落とします。波形は、タブの中でデコードされたファイルです。

区間をドラッグします。**選択範囲を残す** はそこだけを書き出します。**選択範囲を削除** はそれ以外を書き出します。ドラッグが足りないときは **時刻を指定** に開始と終了を秒で入れます。

残りは **調整** です。

- **フェードイン** と **フェードアウト** は最長 5 秒。書き出しの最初と最後を形作ります。ファイルの真ん中のつなぎはクロスフェードしません。
- **音量** は 10% から 200%。100% を超えるとリミッターがピークを押さえます。少し上げる方が、硬いクリップよりきれいです。もともと大きいファイルは、それでも詰まったように聞こえます。
- **速度** は 0.5× から 2×。音程も一緒に動きます。長さだけ変えてキーを保つ処理ではありません。
- **ピークをノーマライズ** は、いちばん大きいサンプルがクリップ直前に来るまで、ファイル全体を同じ量だけ上げます。音量スライダーは上書きされます。小さい部分を大きい部分と同じ大きさにはしません。
- **逆再生** は書き出しを後ろから前にします。

書き出す前に、選択範囲を再生して聞きます。それから形式です。

**MP3 · 320 kbps** がエディターの初期値で、この書き出しを残すファイルにするならこれです。送るだけなら **192 kbps**。声なら **128 kbps**。この編集が最後でないなら **WAV**。

## 大きさを当てずっぽうにしない

最初から最後まで小さいファイルには、正直な直しが二つあります。同じつまみではありません。

[音声ノーマライザー](/ja/normalize-audio) はピークを測り、クリップしない範囲でいちばん大きいゲインをかけます。どこまで上げればいいか分からないときに使います。

[MP3 音量ブースター](/ja/increase-volume) は自分で選ぶ倍率で、上限は 400%、ピークにリミッターがかかります。エディターの音量は 200% で止まります。200% で足りないときが専用ページです。大きい部分がポンピングし始めたら戻してください。

どちらも、配信向けのラウドネス合わせではありません。あれは LUFS で測る長い平均で、マスタリングの仕事です。

## 音と表示名は別

カット、フェード、音量は MP3 をデコードして新しい MP3 を書きます。タイトル、アーティスト、アルバム、ジャケットは音ではありません。タグの塊に入っていて、[タグエディター](/ja/mp3-tag-editor) はその塊だけを書き換え、音声のバイトには触れません。先に音。残すファイルに名前を付けます。先に名前を付けてから新しい MP3 を書き出すと、タグは落ちます。

タグエディターは MP3 だけです。アルバムをまとめては扱えません。珍しいポッドキャストのチャプター欄も引き継ぎません。

## このエディターがしないこと

二つのトラックを重ねてミックスしません。[音声結合](/ja/audio-joiner) はファイルを前後につなぎ、重なりをクロスフェードできます。フェーダーを二つ同時には出しません。

ボーカル除去、ノイズプロファイル、ステム分離もしません。それを約束するブラウザのページは、別の製品の話をしています。
