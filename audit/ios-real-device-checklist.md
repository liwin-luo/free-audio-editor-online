# iOS Safari 真机自测清单（audit/ios-real-device-checklist.md）

> 日期：2026-11-05 · 配套 `audit/runtime-verification-2026-11.md`
> 桌面自动化已验证的部分不重复列；这里只列**必须有 iPhone 真机**才能验证的路径。
> 审计依据：`priority-issues.md` §6（跨浏览器真机矩阵为零）、`tools-inventory.csv` runtime UNVERIFIED 项、90 天计划 §10.3。
> 建议做法：每项跑完在结果列记 PASS / FAIL+截图，FAIL 项回仓库开修复任务。

**准备**：iPhone（iOS 17+），Safari，从"文件"App 放入测试音频（可用任意语音备忘录 + 一首歌）。
**通用检查**：每个工具导出后：① 文件能从 Safari 下载弹窗存到"文件"；② 存下的文件能再次导入本站或用"文件"预览播放。

## A. audio-trimmer / mp3-cutter（核心）
| 检查项 | 预期 |
|---|---|
| 波形拖动选区（手指） | 能拖出选区，把手可微调，不误触页面滚动 |
| 起止时间输入（数字键盘） | 输入 5/10 后导出，时长 = 5s（对应桌面 PASS 项） |
| 选区播放（Play） | 只播放选区 |
| 23 分钟长语音备忘录（约 200MB WAV） | 能打开；>1h 才出内存警告，300MB 拒绝 |
| MP3 192kbps 导出 | 下载成功、外部可播放 |

## B. voice-recorder（桌面只测了拒绝路径）
| 检查项 | 预期 |
|---|---|
| 首次点 Record | 弹权限对话框；允许后开始录音，计时器走动 |
| 拒绝权限 | 显示 "Microphone access was blocked..."（桌面已验证文案，确认 iOS 文案一致） |
| 录 30 秒 → 停止 | 录音进入下方编辑器，可播放 |
| 导出 MP3 | 下载成功 |
| **iOS 专项**：锁屏/切后台 10 秒再回来 | 录音是否中断？页面提示是否明确？ |

## C. music-visualizer（已知 iOS 风险最高）
| 检查项 | 预期 |
|---|---|
| 点 Record video | iOS Safari 不支持 `canvas.captureStream` 录制 → **应显示降级提示而不是静默失败或报错**（对照 F6 教训） |
| 若能录制 | 前台保活要求（录制时长=歌曲时长）：锁屏会中断吗？提示有没有写清楚？ |

## D. audio-to-midi
| 检查项 | 预期 |
|---|---|
| 4 秒琶音转换 | 出结果（桌面 WebGL 有时约 3-4 分钟；iOS 无 WebGL → CPU 更慢，观察是否卡 20% 与是否有进度反馈） |
| 转换期间锁屏/切走 | 回来后是否恢复、失败提示是否可见（对照 F6） |

## E. audio-to-text（弱网路径 = 审计 §4 工具 1 的 UNVERIFIED 项）
| 检查项 | 预期 |
|---|---|
| 首次转录（模型 ~40/80MB 下载）蜂窝弱网 | 有进度提示；失败时**必须有错误提示**（对照 F6：桌面观察到一次静默失败） |
| 下载成功后开飞行模式再转录 | 页面承诺"later runs work offline"——验证缓存真的生效 |
| 10 分钟上限引导 | 超长文件提示是否给出"先去 trimmer 剪"的引导 |

## F. ringtone-maker（修完 F5 后回归）
| 检查项 | 预期 |
|---|---|
| 50s 歌曲全选 → 导出 M4R | 修复后：自动钳到 40s 并提示（当前是 BUG，见 runtime-verification F5） |
| M4R 存到"文件"→ 用 GarageBand/快捷指令设铃声 | 40s 内文件 iOS 接受 |
| 非 AAC 支持场景 | M4R 选项按浏览器能力隐藏（iOS Safari 应支持） |

## G. 通用移动端体验（一次过完全站）
| 检查项 | 预期 |
|---|---|
| 5 个核心页首屏 LCP 体感 | 图片/波形不拖慢首屏（CWV 复测的另一双眼睛） |
| 语言切换 | 跳到对应语言对应页 |
| 导出下载弹窗 | 每个工具都能存文件 |
| 横竖屏切换 | 编辑器布局不破 |

## 记录格式
`工具 / 检查项 / PASS或FAIL / 截图编号 / 备注` ——汇总回填到 `tools-inventory.csv` runtime 列与 `docs/product-facts.md`。
